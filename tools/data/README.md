# Symbol maps

| File | Source |
|---|---|
| `firered.sym` | Vanilla Pokémon FireRed 1.0 symbols, from [pret/pokefirered](https://github.com/pret/pokefirered) (`symbols` branch). |
| `pokefirered_ap.sym` | A local build of [vyneras/pokefirered](https://github.com/vyneras/pokefirered) (`archipelago-dev`). |
| `setmetatile.json` | Metatiles swapped at runtime by `setmetatile` / `MapGridSetMetatileIdAt`, keyed by tileset (from the decomp's scripts and `src/`). |
| `shipped_syms.json` | Symbol addresses inside the shipped Archipelago base patch, made by `align.py` from the two above. |
