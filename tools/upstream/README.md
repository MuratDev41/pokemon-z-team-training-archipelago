# Upstream world

`pokemon_frlg/` is the unmodified Pokémon FireRed and LeafGreen world, version 1.1.5, by Vyneras and contributors
([vyneras/Archipelago](https://github.com/vyneras/Archipelago/releases/tag/1.1.5)). The build reads its Archipelago
base patch and generation data, and regenerates the evolution events from its `events.json`.
